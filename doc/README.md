# SAO STOIC for VAX/VMS: documentation

These documents describe SAO STOIC as it actually behaves: the shipped
`STOIC.EXE` and `RED.EXE` (1985) and a rebuild from the same sources, run on
a SIMH MicroVAX 3900 under VAX/VMS V5.5-2H4 in October 2026. Each claim
cites a source line (`file:line`, relative to `saostoic-text/`) or a test
in `tests/`. A claim that rests only on the source says so.

STOIC is a FORTH-like language written by Roger Hauck and Jonathan Mark at
the Smithsonian Astrophysical Observatory (1980–85). RED is a screen editor
written in it. The GM Research variant is an older kernel of the same
family.

## Reading order

| Document | What it covers |
|---|---|
| [`language.md`](language.md) | The language as a programmer meets it: how a line runs, literals, radix, comparisons, definitions, control structures, the loop stack, branches, strings, the assembler, errors, and the differences from `stoic.mem`. Start here. |
| [`kernel.md`](kernel.md) | The MACRO-32 kernel: registers, memory layout, the dictionary, the compiler and the outer loop, I/O, errors and CTRL/C, startup. |
| [`words.md`](words.md) | Every word in the shipped exe, by branch, with its kind, stack effect, source line and a test. Generated by `tools/word-index --md`; cross-checked against INVENTORY (`data/stoic-inventory.txt`). |
| [`float.md`](float.md) | The float stack, float literals, the `FLOAT<` words, output formats, the MTH$ words, float errors and CALC. |
| [`image.md`](image.md) | IMAGE, which writes the running STOIC as a new `.EXE` without the linker, and SAVE/XLOAD. |
| [`red.md`](red.md) | RED, the screen editor: buffers, the command line, the keypad, the display, and how it differs from `red.mem`. |
| [`build.md`](build.md) | Rebuilding the kernel, STOIC.EXE, RED.EXE and REDHIREZ.EXE from source on V5.5-2H4, and the patched build. |
| [`gm-variant.md`](gm-variant.md) | The GM Research kernel, compared with SAO's. From the source only; it has not been built or run. |
| [`defects.md`](defects.md) | The 49 defects found, each with a repro, the cause, the impact and a suggested fix. |
| [`patches.md`](patches.md) | The Phase 6 patches: one for each fixed defect, with its test, and what behaves differently from the shipped exes. |

| [`cpm-compare.md`](cpm-compare.md) | CP/M STOIC's comparison words, which show that the VAX reversed the intended sense. |

`data/stoic-inventory.txt` is the output of INVENTORY in the shipped exe.

## Where the evidence is

- `saostoic-text/`: Unix-text copies of the VMS sources and manuals.
- `tests/`: the suite (`tools/stoic-suite`), the interactive checks, the
  IMAGE runs (`tests/image/`), the RED screens (`tests/red/`) and the
  Phase 5 checks (`tests/lang/`). `tests/README.md` describes them.
- `tools/`: the scripts that run all of these on the VAX
  (`tools/README.md`).
- `PLAN.md`: the phases, their outcomes and the defect checklist.

`notes/` holds the first design drafts, written from reading the code before
any test. They are kept for history; where they differ from `doc/`, `doc/`
is right.
